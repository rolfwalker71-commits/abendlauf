Wo im Panel was steht

Jede Seite hat genau einen Reiter mit ihren Dateien. Dort wird hochgeladen; in den übrigen Reitern wird nur ausgewählt. Die Reiter Inhalt, Optionen, Erweitert und Sicherheit gehören zu Grav und bleiben unberührt.

Regeln der Automatik

Was die Seite selbst entscheidet – damit sich Überraschungen erklären lassen. Was von Hand eingetragen ist, wird nie überschrieben.

Ranglistebeim Hochladen

  • Nennt der Dateiname Jahr und Lauf (2027-2-abend.pdf, Rangliste Lauf 2 2027.pdf, Gesamtrangliste 2027.pdf), gilt der Name.
  • Sonst zählt der Upload-Zeitpunkt: am Abend oder bis sieben Tage danach → dieser Lauf.
  • Am letzten Abend ist die erste PDF der 3. Abend, die zweite die Gesamtrangliste.
  • Nichts erkannt → Stift-Symbol, von Hand zuordnen.

Fotoalbenbeim Speichern der Startseite

  • Je Laufabend ein Album plus Siegerehrung, mit Titel, Datum und dem Fotografen des jüngsten Albums.
  • Leere Alben erscheinen nirgends auf der Website.
  • Bestehende Alben – auch umbenannte – bleiben unberührt; erkannt an Jahr und Lauf.

Aktuell-TextStartseite

Am letzten Laufabend um 21:00 übernimmt der Text „nach der Rangverkündigung", falls ausgefüllt. Platzhalter füllen sich selbst: {nummer} 33 · {jahr} 2027 · {termine} 18.8. / 25.8. / 1.9. · {vorige_nummer} 32 · {naechste_nummer} 34 · {naechstes_jahr} 2028.

Hinweis „Neu online"zuoberst auf jeder Seite

Vom ersten Laufabend bis eine Woche nach dem letzten: drei Tage lang für jede neue Rangliste des Jahrgangs. Ein von Hand gesetzter Hinweisbanner hat Vorrang.

Austragungsnummerüberall gleich gerechnet

Jahr − 1994 + 1 − ausgefallene Jahre. 2019 → 26., 2026 → 32., 2027 → 33. Ausgefallene Jahre stehen unter Konfiguration › Site.

Pflege mit Claude

Mit dem offiziellen MCP-Server grav-mcp (70 Werkzeuge, lokal getestet) bedient Claude dieselbe Schnittstelle wie das Panel. Nach dem Livegang gibt es zwei getrennte Wege.

direkt live

Inhalte

Texte, Fotos, Ranglisten, Sponsoren, Laufabende

Claude arbeitet per grav-mcp auf der Liveseite, genau wie im Panel. Die Jahresautomatik greift auch dort – ein Upload per Claude wird zugeordnet wie einer von Hand.

über Git

Aussehen & Funktionen

Vorlagen, CSS, Panel-Masken, Automatik

  1. lokal ändern, auf localhost:8100 prüfen
  2. auf GitHub pushen (grav, dann main)
  3. GitHub Action spielt nur das Theme auf den Server

Nie user/pages/ deployen. Ab dem Livegang sind die Inhalte auf dem Server aktueller als im Repository. Sicherung über Grav-Backups oder regelmässiges Zurückholen.

Einrichtung

  1. Auf dem Server einen eigenen Benutzer claude anlegen – nur Seiten und Medien.
  2. Schlüssel erzeugen: bin/plugin api keys:generate --user=claude --name="Laptop Rolf" – einer pro Gerät.
  3. In Claude Code eintragen; der Schlüssel liegt nur in der Umgebungsvariable, nie im Repository:
{
  "mcpServers": {
    "abendlauf": {
      "command": "npx",
      "args": ["-y", "grav-mcp"],
      "env": {
        "GRAV_API_URL": "https://www.abendlauf.ch/api",
        "GRAV_API_KEY": "${ABENDLAUF_API_KEY}"
      }
    }
  }
}

Für Entwicklung

Die ausführliche Fassung für Claude-Sitzungen steht in CLAUDE.md im Repository.

werkzeuge/grav-einrichten.sh                 # Grav-Kern holen (nicht versioniert)
php -S localhost:8100 system/router.php      # starten
rm -rf cache/twig cache/compiled             # nach Template-Änderungen

php werkzeuge/pruefe-saison.php              # Regeln der Jahresautomatik
python3 werkzeuge/pruefe-backend.py          # jedes Feld im Panel bearbeitbar?
GRAV_TOKEN=… python3 werkzeuge/pruefe-feldtypen.py
python3 werkzeuge/fotos-holen.py 2024        # Alben von der alten Seite

Medienfelder

Genau ein pagemedia pro Seite (die ganze Medienverwaltung), alles Auswählende ist pagemediaselect und speichert einen Text.

Farben

Tokens am Anfang von css/main.css, hell und dunkel. Signalgelb nur als Fläche mit dunkler Schrift; Cyan als Schrift immer --accent-text.

Panel formatiert um

Speichern im Panel ändert Einrückung und macht Datumsfelder zu Zeitstempeln – Inhaltsdateien nie per Textersetzung bearbeiten.
